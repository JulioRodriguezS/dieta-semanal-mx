## 📖 ¿Qué es esto?

Un sitio web sencillo y bonito con un **plan de alimentación semanal** basado en comida mexicana. Pensado para comer bien, variado y sin reventar la cartera.

Incluye desayuno, colación, comida y cena para cada día de la semana, más una lista de compras con los ingredientes clave que siempre conviene tener en la cocina.

---

## ✨ Características

- 🗓️ **7 días completos** de menú con 4 comidas cada uno
- 🧭 **Navegación sticky** para saltar entre días con un clic
- 🎨 **Tarjetas con código de color** por tipo de comida (desayuno, colación, comida, cena)
- 🛒 **Lista de compras** con grid visual de ingredientes
- 📱 **Diseño responsivo** que se ve bien en celular, tablet y escritorio
- 🎬 **Animaciones suaves** de fade-in al hacer scroll
- 🪶 **Cero dependencias** — un solo archivo HTML, nada de frameworks ni librerías externas

## 📦 Instalación

No necesitas instalar nada. Solo clona el repo:

```bash
git clone https://github.com/JulioRodriguezS/dieta-semanal-mx.git
cd dieta-semanal-mx
```

Y abre `index.html` en tu navegador favorito. Listo.

---

## 🌐 Despliegue en GitHub Pages

1. Sube el repositorio a GitHub.
2. Ve a **Settings** → **Pages**.
3. En **Source** selecciona la rama `main` y la carpeta `/ (root)`.
4. Haz clic en **Save**.
5. En unos segundos tu sitio estará disponible en:
   ```
   https://JulioRodriguezS.github.io/dieta-semanal-mx/
   ```
